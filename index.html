Dexterous Hand Grasping and Pick-and-Place

Yuhua Zhang

Demo

Built PyBullet-based dexterous manipulation simulations for both desktop clearing and pick-and-place tasks. For grasping, KUKA Allegro and Franka Panda robots perform IK-based control to clear randomly spawned YCB objects off a table. For pick-and-place, a KUKA IIWA7 manipulator with an Allegro dexterous hand picks objects and places them into a custom multi-body basket using Slerp interpolation for smooth motion. Includes real-time joint debugging via GUI sliders.
